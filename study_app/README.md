# تفوّق ١٢ — منصة اختبارات الصف الثاني عشر (سلطنة عُمان)

## التشغيل
يتطلب Node.js 18 أو أحدث، ولا يحتاج أي مكتبات إضافية. إذا كان المنفذ 3000 مستخدماً: `PORT=4012 npm start`

```bash
npm start            # أو: node server.js
```

- موقع الطلاب: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin
- كلمة مرور الإدارة الافتراضية: `oman2026` — غيّرها فوراً من «الإعدادات» في لوحة التحكم.
  (أو حدّدها قبل أول تشغيل: `ADMIN_PASSWORD=كلمة_سرية npm start`)

## طريقة العمل
- كل مادة مقسمة إلى وحدات، وكل درس = مرحلة فيها 10–12 سؤال اختيار من متعدد.
- يبدأ الطالب من المرحلة الأولى، وتُفتح المرحلة التالية عند الحصول على 60٪ أو أكثر.
- تُخلط الأسئلة والخيارات في كل محاولة، ويظهر الشرح بعد كل إجابة.
- يُحفظ تقدم الطالب في متصفحه، وتُرسل نتائج المحاولات (بدون أسماء) لإحصائيات لوحة التحكم.

## البيانات
- `data/seed/` بنك الأسئلة الأولي (7 مواد، 28 مرحلة، 299 سؤالاً).
- `data/db.json` يُنشأ تلقائياً عند أول تشغيل، وفيه كل التعديلات التي تتم من لوحة التحكم.
  احذفه لإعادة البيانات إلى البنك الأولي. استخدم «تصدير الأسئلة» للنسخ الاحتياطي.
